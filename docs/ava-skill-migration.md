# 专家迁移到上游 AVA Skill

专家直接预加载
[AVA Skill](https://github.com/antvis/AVA/tree/codex/ava-skill-reports/skills/ava)，打包时固定到
`d09b06d0a90e6beb8e5ac4cbdca55b8a70691f0f`，校验归档 SHA-256 后原样提取完整目录。本仓库只维护版本引用与专家身份，不维护另一份 Skill、报告模板或脚本。MCP 服务、连接器、运行 TGZ、库导出和相关依赖均已移除。

## 功能对照

| 能力                                           | Skill 专家的变化                                                                                                                        |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 文件、内联数据、数据库、飞书                   | 核心入口保留，改为 `ava source` 与原生配置。具体类型取决于实际安装的 CLI 版本。                                                         |
| 结构、只读 SQL、语义、图表、会话释放           | 分别使用 `schema`、`query`、`semantic`、`viz`、`dispose`，不再通过 MCP。                                                                |
| 数据质量画像                                   | 新增直接使用 `ava profile` 的流程；旧 MCP 没有对应工具。                                                                                |
| 业务口径复用                                   | Skill 支持维护本地 Semantic JSON，合并后载入会话；旧工具只替换当前会话定义。                                                            |
| 完整 HTML 报告、指标、表格、SQL、19 类图表绑定 | 使用随包 `scripts/report.mjs query/render`，核心交付保留。原 `ava_artifact` 调用参数不能直接复用。                                      |
| 查询证据                                       | 由连接内最近 32 次查询改为任务目录的持久内容哈希文件和索引；会话释放后仍可生成报告。普通 `ava query` 不自动记录报告证据。               |
| 追问报告                                       | 按稳定章节 ID 合并前一份 JSON，保留早先问题与证据；输出使用新文件名。                                                                   |
| 报告样式                                       | 保留上游默认模板，新增任务内自定义模板；呈现调整无需重跑查询。                                                                          |
| 错误摘要、截断和图表失败                       | 报告脚本保留受控摘要、截断不绘图、图表失败仍交付表格和 SQL；直接 CLI 命令错误由 Skill 要求代理摘要，不能承诺沿用 MCP 的统一运行时过滤。 |
| 输出保护                                       | 报告 HTML、JSON 和证据文件保留 `600` 与不覆盖；独立 CLI `viz` 不再经过本项目的权限加固。                                                |

## 不再由 MCP 提供的保护与安装行为

- 专家不再带固定 Release TGZ 的 MCP 自动启动配置。接收方需要可用的 Node.js 22.13+、AVA CLI
  4.x、命令工具与 Unix socket 权限；首次环境检查按 Skill 执行，原 `ava_check` 不再提供。
- 不再经过本项目的私有输入副本、SQLite
  WAL 快照、输入目录限制和副本清理流程。CLI 自身的读写限制不能视为同等隔离。
- 不再由 MCP 连接跟踪会话归属、串行化操作、关闭清理及保留目录报告。CLI 会话由任务保存 ID 并主动释放；超时或不确定结果仍不能自动重试或释放。
- 通用 HTTP(S) 文件与 SSH 不再经过本项目的禁用入口；可用性及校验取决于实际 CLI。上游 Skill 说明的能力不等于当前安装版本全部支持，不应据此宣称已验证远程文件、SSH、SQL
  Server 或 Snowflake。
- 数据和查询结果仍返回 WorkBuddy；报告仍内嵌数据，交互图表仍加载 unpkg.com 的第三方脚本。模型文本提取仍需额外配置及对应数据授权。
